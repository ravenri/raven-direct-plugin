# Customer Diligence: Output Structure

This file defines what the skill renders: sections, order, fields and block format. Edit it to change the
output. SKILL.md owns the procedure; this file owns the shape. Where they touch the same thing, this file
wins for layout and SKILL.md wins for procedure and sourcing.

`[Bracketed italic text]` is a render instruction, not output. Do not delete the Overview or the
Pass 2 section; SKILL.md requires both.

**Render rule for every section below:** a table, row, block or paragraph is rendered only when the
sources carry data for it. Anything not disclosed is not rendered in place; it is listed once under
Diligence Gaps.
