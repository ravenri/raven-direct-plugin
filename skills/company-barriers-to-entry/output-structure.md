# Barriers to Entry — Output Structure

Defines **what** the skill renders: sections, order, tables. Edit this to change the output. SKILL.md
owns the procedure (retrieval, verdict handling, peer step, diligence close, Pass 2); this file owns
the shape. When they touch the same thing, this file wins for layout, SKILL.md wins for procedure.

**How to edit:** add/remove a field = add/remove a row; reorder sections = reorder blocks;
`[bracketed italic]` are render instructions, not output — keep them. Do not delete the Pass 2 findings
section.
