# Source checklist

Each source is recorded as read, empty, not generated, or not read with the reason.

## Step 1: registers

1. Deal overview and document list: overview and document list tools. Stop if not ready.
2. Open Data Gaps (2100): the five-category register with a diligence ask and a source for each gap.
3. Diligence Focus Areas (2101): ranked areas with actions.
4. Investment Risks (919): risks, mitigant class, diligence focus. Where it differs from Diligence Focus Areas, report both.

A gap's SOURCE field names the prompt it came from. Open that prompt only when an item needs a figure the entry does not carry.

## Step 4: checks

1. Deal documents, for the status and date checks and the source conflict checks.
2. Competition dashboard and Barriers to Entry dashboard: claimed versus supported, data conflicts.
3. Peer set: comp analysis dashboard, else the comp-set and its filings.
4. Credit Q&A: the team's own logged questions, if any.
