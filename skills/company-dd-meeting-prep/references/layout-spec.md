# Layout spec

Use only when `assets/dd_meeting_prep_template.docx` cannot be opened. The values are taken from the template.

1. Page: Letter, portrait, 8.5 by 11 inches. Margins 0.8 inch left and right, 0.7 inch top and bottom.
2. Font: Open Sans throughout.
3. Sizes: title 20 pt; section headings 11 pt with a thin rule beneath; body and table text 9 pt; source lines 7.5 pt in gray (5A636A).
4. Color: black text. Table header cells gray D9D9D9 and bold. Label cells light gray F2F2F2. No color bars, no logo, no branding.
5. Tables: column widths sized to content, not equal. Header row repeats across pages.
6. Footer: "Confidential: internal work product" on the left and the page number on the right.
7. Order: title, logistics table, confidential line, Objectives, Questions, Follow-up Requests, then Appendices A to E. Questions sit under bold topic headings, each with a short credit mechanism beneath it. Each question has a bold Probe line, then a source line in 7.5 pt gray italic indented under it. Appendix A starts on a new page and keeps the gap list by category. Appendix tables with long text may use 8 pt.
